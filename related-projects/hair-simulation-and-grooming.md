# Hair Simulation and Grooming

This category collects related projects and tools on hairstyle modeling, hair grooming, and simulation that inform robotic haircutting research.

- [BarberGPT](https://www.barbergpt.ai/): an online AI hairstyle visualization tool for previewing different hairstyles from user photos. It is relevant as a consumer-facing reference for target-hairstyle preview, user preference communication, and appearance-oriented validation in robotic haircutting workflows.
- [Digital-Salon](https://github.com/Dai0731csc/Digital-Salon): a fork of the original Digital Salon project. It supports hairstyle generation, 3D hair grooming, and hair simulation, which are useful for target-hairstyle representation and visual validation in robotic haircutting workflows.
- [HairFastGAN](https://github.com/Dai0731csc/HairFastGAN): a fork of the original HairFastGAN project. It is relevant to virtual hairstyle fitting and reference-based hair transfer, which are useful for target-hairstyle preview and appearance-oriented validation in robotic haircutting workflows.
