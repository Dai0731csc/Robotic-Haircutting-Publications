# Education and Training

This directory collects course-project planning materials and related training resources connected to robotic haircutting. These materials complement the publications and implementation work collected elsewhere in this repository.

The resources organized here are intended to support student onboarding and project-based learning around robotic haircutting research.

## Materials

- [Capstone Weekly Planning 2026](Capstone%20Weekly%20Planning_2026.pdf): a course-project planning document for a robotic hair cutting system, outlining a staged training and implementation path for student participation.

Additional educational planning materials may be added here as this part of the project develops.
